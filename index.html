使用說明

三種寫法互相同步

編輯全漢字、全羅、羅馬字加音調數字任一欄，另外兩欄會自動反推。沒有固定以哪個為主——頁面上方會顯示「目前以哪個欄位為準」；想改成以羅馬字為主，直接編輯全羅或數字調欄位即可，漢字會自動跟著配對過去。

轉換錯了怎麼辦

點擊解析結果列裡的任何一個詞，會打開修改面板：如果辭典本來就有多個讀音（例如破音字），會列成按鈕可以直接點選；也可以直接輸入正確的羅馬字（變音標或數字調都可以），甚至上傳這個詞自己的音檔。儲存後會存進「自訂詞庫」，疊加在官方辭典之上，下次打開頁面還在，語音也會跟著用你存的版本。

辭典沒收錄的字

辭典沒有的漢字，或是羅馬字沒對應到任何漢字，都會在解析結果列標示 ⚠ 警告。點擊一樣可以打開修改面板，自己補上讀音／漢字／音檔。

變調後（連讀參考）

解析結果下方會多顯示一列「變調後」，套用台語標準連讀變調規則（1→7→3→2→1 循環、第5聲另外分支到7、入聲 4↔8 對調、喉塞韻尾 -h 的入聲則去 h 變舒聲），把每個字的本調換算成連續講話時實際會變成的調——只有整句（依標點斷句）最後一個音節維持本調，其餘都變調。這一列本身純粹是參考用文字，不會回寫到其他欄位。就算辭典查無讀音、只顯示〔數字調〕占位的詞，一樣可以套用變調規則算出參考音，因為變調只需要知道本調數字，不需要真的查到字。

目前的變調分組是「遇到主要標點就斷開」的簡化版，沒有處理輕聲（--）和疊字變調（如「紅紅紅」）這類較特殊的規則，複雜句子的分組可能跟真實語感有落差，僅供參考。

沒有音檔時，借用變調後同音字的錄音

有些詞辭典本身沒有音檔（教育部只錄「單字能成詞」的讀音，很多字單獨存在時反而沒錄音），或是查無此字。遇到這種情況，系統會用「變調後」算出來的讀音，反查辭典裡有沒有別的字剛好本調就唸這個音——找得到的話，就借用那個字的錄音來播放（畫面上標示淺藍色底線加 ~，滑鼠移過去會顯示借用自哪個字）。原則是：詞本身有音檔就優先用它自己的（主）；沒有的話，才用變調後查到的音檔代替（副）。因為變調後的讀音在物理上就是那個聲音，跟是哪個字沒有關係，借用來播放是合理的。

播放語音

依詞序接續播放教育部辭典的真人錄音（不是語音合成），可調整語速。串接播放沒有連續語流的連讀變調，逐字聽起來會比整句自然語音生硬一些，這是音檔本身（單字錄音）的性質，沒辦法完全消除，但詞與詞之間已依標點做了停頓節奏調整。

下載語音（WAV）

你自己上傳的音檔一定能合併下載；教育部官方辭典音檔的伺服器不開放跨網域讀取，預設遇到官方音檔會改列出個別連結供手動另存。想連官方音檔也一起合併下載，有兩種選擇，可以只設一個、也可以兩個都設：

  • 本機：改用附的 serve.py 開啟（需要 Python）：終端機執行 python serve.py，再開 http://localhost:8791/index.html。
  • 雲端（連 GitHub Pages 上也能用）：把 cloudflare-worker.js 部署到自己的 Cloudflare 帳號（免費），再把拿到的網址填進 export.js 的 EXTERNAL_PROXY_BASE。詳細步驟見 README「讓「下載語音」在 GitHub Pages 上也能合併官方音檔」。

兩種原理相同：由你自己控制的電腦或雲端帳號代為讀取音檔、再回傳給頁面，不經任何你不認識的第三方伺服器。

自訂詞庫格式

CSV 或 JSON，UTF-8 編碼。CSV 需含表頭，欄位為「漢字,羅馬字,音檔,備註」（後兩欄可留空）；羅馬字可用全羅變音標或數字調任一種寫法，多音節詞用「-」連接。JSON 則為物件陣列，鍵名可用中文或英文：{"漢字":"...","羅馬字":"...","音檔":"（選填）","備註":"（選填）"}。範例檔： custom-dictionary-example.csv、 custom-dictionary-example.json。如果是用 Excel 編輯 CSV，存檔時選「CSV UTF-8」，不要選一般「CSV」，不然中文字用 Excel 直接雙擊開啟時會變亂碼（本工具匯入不受影響，這只影響你自己在 Excel 裡看檔案）。

自己的錄音／音檔

不需要架網站放檔案。「音檔」欄位可以直接寫檔名（例如 a-ma.mp3），再用「上傳自訂音檔」選取本機音檔（mp3／wav／ogg 皆可），系統會依檔名自動配對（區分大小寫、副檔名都要一致）；也可以填完整的 http(s) 網址。音檔存在瀏覽器本機（IndexedDB），不會上傳到任何伺服器。
